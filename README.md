# VideoContentRanking

##   Описание проекта
Пайплайн для автоматического выделения сцен из длинных видео и построения признаков для их анализа.  
Единицей анализа является **сегмент сцены**, объединяющий несколько монтажных склеек по речи.  
Результат — таблица (CSV) с временными метками, текстом речи и аудиопризнаками.

##  Архитектура
1. Извлечение аудио из видео (`ffmpeg`).
2. Распознавание речи (`faster-whisper`).
3. Слияние речевых сегментов.
4. Детекция монтажных склеек (`PySceneDetect`).
5. Объединение речи и склеек в сцены.
6. Извлечение аудиопризнаков (RMS, LUFS).
7. Нормировка признаков (z-score).
8. Сохранение результата в CSV.

##  Запуск на своём видео

1. Скопируйте ваш фильм в папку `data/raw/`.  
   Например: `data/raw/my_movie.mp4`

2. В файле `config.yaml` укажите путь к видео и имя выходного CSV:
   ```yaml
   video:
     input_path: "data/raw/my_movie.mp4"
     output_csv: "data/processed/my_movie_scenes.csv"

##   Как запустить
```bash
python main.py --config config.yaml
